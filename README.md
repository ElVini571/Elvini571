### 📌 Projeto em destaque

#### Detecção de fraudes em cartões de crédito

Projeto educacional desenvolvido no Projeto Integrador I de Ciência de Dados da UFMS Digital, com análise de transações e modelos de Machine Learning para identificar possíveis fraudes.

Fui responsável pela implementação técnica, incluindo preparação e análise dos dados, treinamento e avaliação dos modelos, dashboards no Power BI, simulador em Streamlit e configuração com Docker. A escolha da base, o planejamento e a definição do objetivo foram realizados em equipe.

**Tecnologias utilizadas**  
Python · pandas · NumPy · scikit-learn · Matplotlib · Power BI · Streamlit · Docker

[📂 Conheça o projeto e suas demonstrações](https://github.com/ElVini571/credit-card-fraud-detection)
